TUS ERRORES — ROOT CAUSE ANALYSIS
═══════════════════════════════════════════════════════════════════════════════

Error 1: '[VisionLLM ERROR] 'HfMoondream' object has no attribute all_tied_weights_keys'
─────────────────────────────────────────────────────────────────────────────
  Causa: Python 3.13 (tienes 3.13.14)
  Moondream2 SOLO funciona en Python 3.10/3.11/3.12
  
  Solución: Instala Python 3.12 y ejecuta todo con: py -3.12 main.py

Error 2: '[TemplateDetector ERROR] No se pudo obtener resolución: [WinError 2]'
─────────────────────────────────────────────────────────────────────────────
  Causa: ffprobe.exe no se encuentra en la ruta .\ffmpeg\bin\
  ffmpeg NO está instalado globalmente ni en esa ruta
  
  Solución: winget install Gyan.FFmpeg

Error 3: '[WARNING] LLM no disponible, usando modo manual'
─────────────────────────────────────────────────────────────────────────────
  Causa: PyTorch, transformers, moondream NO están instalados
  Necesarios para LLM mode pero NO para FAST mode
  
  Solución: py -3.12 -m pip install torch torchvision transformers moondream

PREGUNTAS FRECUENTES
═══════════════════════════════════════════════════════════════════════════════

P: ¿Por qué Python 3.13 no funciona?
R: Moondream2 usa API interna de transformers que cambió en 3.13.
   Espera a Python 3.14 o usa 3.12 por ahora (más estable).

P: ¿Tengo que instalar Python 3.12 si solo uso FAST mode?
R: No. Python 3.13 funciona OK para modo FAST (sin LLM).
   Solo necesitas 3.12 para HYBRID/LLM_ONLY modes.

P: ¿Por qué el token de Hugging Face?
R: Sin token: ~5 min primera descarga de Moondream2
   Con token: ~1 min (rate limit 100/hr vs 12/hr)

P: ¿Está roto algo?
R: No. Sistema funciona correctamente, faltaban dependencias.
   Keywords + HF token todo OK, solo necesita PyTorch instalado.
