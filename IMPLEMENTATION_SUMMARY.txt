🚀 USAGE — Quick Start
─────────────────────────────────────────────────────────────────────────────

1. DEFAULT (Spanish keywords already loaded):
   $ python main.py D:\gameplay.mp4
   # Uses config.json: language="es", game_type="lol"

2. WITH HUGGING FACE TOKEN (optional, faster):
