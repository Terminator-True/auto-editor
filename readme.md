# Auto-editor tool

This tool is used to process a video and detect highlights audibly or visually. 

It visually looks for text that is configured in the config.json file. And sonically it looks for irregularities that indicate a volume increase.

To be used, it must be executed as follows:

`python main.py <video.mp4>`

To install its dependencies: 

` pip install -r requirements.txt `
